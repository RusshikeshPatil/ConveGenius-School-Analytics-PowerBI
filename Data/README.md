# Data

The project was developed using multiple education-related datasets:

* School Registry
* Student Registry
* Teacher Registry
* Attendance Dataset
* Assessment Dataset

These datasets were used for data cleaning, transformation, modeling, KPI development, and dashboard creation in Power BI.

## Privacy Notice

The original datasets are not included in this public repository because they may contain school, student, teacher, attendance, or assessment-level information.

The dashboard screenshots and Power BI report are provided for portfolio and demonstration purposes, subject to applicable data-sharing permissions.
